# Prerequisites

Before you begin using SmartAPIForge, ensure your development environment meets the following requirements.

## System Requirements

### Operating System

SmartAPIForge supports the following operating systems:

- **macOS** 10.15 (Catalina) or later
- **Windows** 10/11 with WSL2
- **Linux** (Ubuntu 20.04+, Debian 11+, or equivalent)

### Hardware Requirements

**Minimum:**
- 4 GB RAM
- 2 CPU cores
- 10 GB available disk space

**Recommended:**
- 8 GB RAM or more
- 4 CPU cores or more
- 20 GB available disk space
- SSD for better performance

## Required Software

### Node.js

SmartAPIForge requires **Node.js 18.17.0 or higher**.

  <TabsContent value="nvm">
    Install Node.js using Node Version Manager:
    
    ```bash
    # Install NVM
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
    
    # Install Node.js 18
    nvm install 18
    nvm use 18

    node --version  # Should show v18.x.x or higher
    ```

    2. Download the LTS version (18.x or higher)
    3. Run the installer
    4. Verify installation:
    
    ```bash
    node --version  # Should show v18.x.x or higher
    ```
  </TabsContent>
</Tabs>

<Callout type="info" title="Why Node.js 18+?">
  SmartAPIForge uses Next.js 15 and React 19, which require Node.js 18.17.0 or higher for optimal performance and compatibility.
</Callout>

Git is required for version control and GitHub integration.

```bash
# Check if Git is installed
git --version  # Should show 2.40.0 or higher

# Install Git if needed
# macOS (using Homebrew)
brew install git

# Ubuntu/Debian
sudo apt-get install git

# Windows
# Download from https://git-scm.com/download/win
```

## Required Accounts

### Supabase Account

SmartAPIForge uses Supabase for authentication and database management.

1. Sign up at [supabase.com](https://supabase.com)
2. Create a new project
3. Note your project URL and API keys

<Callout type="success" title="Free Tier Available">
  Supabase offers a generous free tier that's perfect for development and small projects.
</Callout>

### OpenAI Account

Required for AI-powered code generation.

1. Sign up at [platform.openai.com](https://platform.openai.com)
2. Generate an API key
3. Add credits to your account (minimum $5 recommended)

**Estimated Costs:**
- Average API generation: $0.02 - $0.05
- 100 generations: ~$3-5

### E2B Account

Required for secure sandbox execution.

1. Sign up at [e2b.dev](https://e2b.dev)
2. Get your API key from the dashboard
3. Note your template ID

**Free Tier:**
- 100 sandbox hours per month
- Sufficient for development and testing

### Inngest Account

Required for background job processing.

1. Sign up at [inngest.com](https://inngest.com)
2. Create a new app
3. Get your event key and signing key

**Free Tier:**
- 50,000 function runs per month
- Perfect for getting started

## Troubleshooting

### Node.js Version Issues

If you have an older version of Node.js:

```bash
# Using NVM
nvm install 18
nvm alias default 18

# Verify
node --version
```

### Permission Errors

If you encounter permission errors when installing packages globally:

```bash
# macOS/Linux: Use sudo (not recommended)
sudo npm install -g pnpm

# Better: Configure npm to use a different directory
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

### WSL2 Setup (Windows)

For Windows users, we recommend using WSL2:

1. Enable WSL2: [docs.microsoft.com/en-us/windows/wsl/install](https://docs.microsoft.com/en-us/windows/wsl/install)
2. Install Ubuntu from Microsoft Store
3. Follow Linux installation instructions
