# Your First API - Complete Tutorial

Build a complete Todo API from scratch in under 10 minutes. This tutorial covers everything from generation to deployment.

## What You'll Build

A fully functional Todo API with:

- ✅ Create, read, update, and delete todos
- ✅ Mark todos as complete
- ✅ Filter by status
- ✅ Input validation
- ✅ Error handling
- ✅ Automated tests
- ✅ OpenAPI documentation
- ✅ Live deployment

<Callout type="info" title="Prerequisites">
  Make sure you've completed the [Installation](/docs/getting-started/installation) and are signed in to SmartAPIForge.
</Callout>

## Step 1: Create Your Project

1. Navigate to [http://localhost:3000](http://localhost:3000)
2. Click **New Project** or the **+** button
3. Enter project details:
   - **Name:** Todo API
   - **Description:** A simple todo management API
4. Click **Create Project**

You'll be redirected to the project workspace.

## Step 2: Write Your Prompt

In the AI prompt box, describe your API in detail:

```
Create a REST API for managing todos with the following features:

Data Model:
- id: unique identifier (UUID)
- title: string (required, max 200 characters)
- description: string (optional, max 1000 characters)
- status: enum ("pending" or "completed")
- priority: enum ("low", "medium", "high")
- due_date: datetime (optional)
- created_at: datetime (auto-generated)
- updated_at: datetime (auto-updated)

Endpoints:
1. POST /todos - Create a new todo
2. GET /todos - List all todos with optional filters (status, priority)
3. GET /todos/\{id\} - Get a specific todo by ID
4. PUT /todos/\{id\} - Update a todo
5. DELETE /todos/\{id\} - Delete a todo
6. POST /todos/\{id\}/complete - Mark a todo as completed

Requirements:
- Input validation for all fields
- Proper error handling with meaningful messages
- Return 404 for non-existent todos
- Return 400 for invalid input
- Include automated tests for all endpoints
- Use FastAPI framework
- Include OpenAPI/Swagger documentation
```

<Callout type="success" title="Detailed Prompts Work Best">
  The more specific your prompt, the better the generated API will match your needs.
</Callout>

### Key Files

**main.py** - Application entry point:

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from routes import todos

app = FastAPI(
    title="Todo API",
    description="A simple todo management API",
    version="1.0.0"
)

# CORS middleware
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Include routers
app.include_router(todos.router, prefix="/todos", tags=["todos"])

@app.get("/")
async def root():
    return {"message": "Todo API is running"}

@app.get("/health")
async def health_check():
    return {"status": "healthy"}
```

**models/todo.py** - Data model:

```python
from pydantic import BaseModel, Field
from datetime import datetime
from enum import Enum
from typing import Optional
import uuid

class TodoStatus(str, Enum):
    PENDING = "pending"
    COMPLETED = "completed"

class TodoPriority(str, Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"

class Todo(BaseModel):
    id: str = Field(default_factory=lambda: str(uuid.uuid4()))
    title: str = Field(..., max_length=200)
    description: Optional[str] = Field(None, max_length=1000)
    status: TodoStatus = TodoStatus.PENDING
    priority: TodoPriority = TodoPriority.MEDIUM
    due_date: Optional[datetime] = None
    created_at: datetime = Field(default_factory=datetime.now)
    updated_at: datetime = Field(default_factory=datetime.now)
    
    class Config:
        json_schema_extra = {
            "example": {
                "title": "Complete project documentation",
                "description": "Write comprehensive docs for the API",
                "status": "pending",
                "priority": "high",
                "due_date": "2024-12-31T23:59:59"
            }
        }
```

**routes/todos.py** - API endpoints:

```python
from fastapi import APIRouter, HTTPException, Query
from typing import List, Optional
from models.todo import Todo, TodoStatus, TodoPriority
from schemas.todo_schema import TodoCreate, TodoUpdate

router = APIRouter()

# In-memory storage (replace with database in production)
todos_db: dict[str, Todo] = {}

@router.post("/", response_model=Todo, status_code=201)
async def create_todo(todo: TodoCreate):
    """Create a new todo"""
    new_todo = Todo(**todo.dict())
    todos_db[new_todo.id] = new_todo
    return new_todo

@router.get("/", response_model=List[Todo])
async def list_todos(
    status: Optional[TodoStatus] = Query(None),
    priority: Optional[TodoPriority] = Query(None)
):
    """List all todos with optional filters"""
    todos = list(todos_db.values())
    
    if status:
        todos = [t for t in todos if t.status == status]
    if priority:
        todos = [t for t in todos if t.priority == priority]
    
    return todos

@router.get("/{todo_id}", response_model=Todo)
async def get_todo(todo_id: str):
    """Get a specific todo by ID"""
    if todo_id not in todos_db:
        raise HTTPException(status_code=404, detail="Todo not found")
    return todos_db[todo_id]

@router.put("/{todo_id}", response_model=Todo)
async def update_todo(todo_id: str, todo_update: TodoUpdate):
    """Update a todo"""
    if todo_id not in todos_db:
        raise HTTPException(status_code=404, detail="Todo not found")
    
    todo = todos_db[todo_id]
    update_data = todo_update.dict(exclude_unset=True)
    
    for field, value in update_data.items():
        setattr(todo, field, value)
    
    todo.updated_at = datetime.now()
    return todo

@router.delete("/{todo_id}", status_code=204)
async def delete_todo(todo_id: str):
    """Delete a todo"""
    if todo_id not in todos_db:
        raise HTTPException(status_code=404, detail="Todo not found")
    
    del todos_db[todo_id]
    return None

@router.post("/{todo_id}/complete", response_model=Todo)
async def complete_todo(todo_id: str):
    """Mark a todo as completed"""
    if todo_id not in todos_db:
        raise HTTPException(status_code=404, detail="Todo not found")
    
    todo = todos_db[todo_id]
    todo.status = TodoStatus.COMPLETED
    todo.updated_at = datetime.now()
    return todo
```

## Troubleshooting

### API Not Responding

**Problem:** Endpoints return 404

**Solution:**
1. Check server is running in terminal
2. Verify URL is correct
3. Check route prefixes in main.py

### Validation Errors

**Problem:** 422 Unprocessable Entity

**Solution:**
1. Check request body matches schema
2. Verify required fields are present
3. Check data types are correct

### Tests Failing

**Problem:** Some tests fail

**Solution:**
1. Read test output carefully
2. Check test expectations match implementation
3. Run tests individually: `pytest tests/test_todos.py::test_name -v`
